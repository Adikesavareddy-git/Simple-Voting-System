# Simple Voting System – Python

A basic command-line voting system built using Python.  
Users can vote for predefined candidates, and the program counts votes,
handles invalid inputs, and announces the winner.

## Features
- Predefined candidates
- Vote validation
- Vote counting using dictionary
- Winner declaration

## How to Run
1. Install Python 3
2. Clone the repository
3. Run the program:

'''bash
python voting_system.py
